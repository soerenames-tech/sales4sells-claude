# Sales4Sells · Claude-Skill für das Marketing-Team

Mit diesem Skill kennt [Claude](https://claude.ai) das Angebot von Sales4Sells (das **Umstieg-Modell**), unsere Zielgruppe und unsere Regeln. Damit hilft dir Claude bei deinen TikTok-Slideshows und Instagram-Beschreibungen, bei Entwürfen für deine Nachrichten (Erstnachrichten, Follow-ups, Einwände), beim Text-Check und beim Tagesbericht.

> **Für wen?** Poster und Marketer im Team von Sales4Sells. Die ausführliche Anleitung mit Video findest du im Videokurs, Modul „Claude einrichten“.

---

## 1. Herunterladen

**[sales4sells-content.zip herunterladen](https://github.com/soerenames-tech/sales4sells-claude/releases/latest/download/sales4sells-content.zip)**
(oder rechts unter „Releases“ → neueste Version → `sales4sells-content.zip`)

Die Datei **nicht entpacken**.

## 2. In Claude installieren (einmalig, am besten am Laptop)

1. [claude.ai](https://claude.ai) öffnen und anmelden
2. Unten links auf deinen Namen → **Settings** (Einstellungen)
3. Code-Ausführung einschalten: **Code execution and file creation** (im neuen Layout: **Create and edit files**)
4. **Skills** öffnen (je nach Version unter Settings oder **Customize → Skills**) → **Upload a skill** → `sales4sells-content.zip` auswählen
5. Schalter bei **sales4sells-content** einschalten

> Die Menünamen können je nach Sprache und Version leicht abweichen. **Das kostenlose Claude-Konto reicht** – Skills gibt es auch im Gratis-Plan (dort gilt nur ein Nachrichtenlimit pro Tag). Den Bereich „Skills“ siehst du erst, wenn die Code-Ausführung an ist. Klappt es trotzdem nicht? → Abschnitt 4.

## 3. Testen

Neuen Chat öffnen und schreiben:

```
Was ist das Umstieg-Modell von Sales4Sells?
```

Wenn Claude die vier Stufen erklärt (Lernen → Starten → Reduzieren → Umsteigen), ist der Skill aktiv.

## 4. Ohne Skill: Starter-Text

Skill klappt nicht (z. B. am Handy)? Kopiere den Inhalt von **[starter-text.txt](starter-text.txt)** am Anfang jedes neuen Chats hinein. Dann kennt Claude in diesem Chat die wichtigsten Infos und Regeln.

## 5. Was du Claude fragen kannst

Fertige Prompts zum Kopieren für alle Alltagssituationen: **[PROMPTS.md](PROMPTS.md)**

Die wichtigsten auf einen Blick:

| Du willst … | Schreib Claude … |
|---|---|
| Eine Slideshow für TikTok | `Schreib mir eine TikTok-Slideshow (6 Bilder) im Format POV zum Thema Pendeln.` |
| Eine Instagram-Beschreibung | `Ich poste 3 Bilder aus Brasilien: … Gib mir 5 kurze, normale Beschreibungen.` |
| Auf einen Kommentar antworten | `Jemand hat kommentiert: „…“ – was antworte ich öffentlich?` |
| Entwurf nach einem Like | `Jemand hat meine Slideshow über … geliked. Gib mir 2 kurze Entwürfe für eine erste Nachricht.` |
| Deinen Text prüfen | `Check mal meinen Text, bevor ich poste: …` |
| Deinen Tagesbericht schreiben | `Mach mir einen Tagesbericht aus diesen Stichpunkten: …` |

## 6. Drei Regeln

1. **Keine sensiblen Daten** in Claude – keine Telefonnummern oder E-Mail-Adressen von Interessenten. Nachrichten und Screenshots einfügen ist okay.
2. **Eigene Worte:** Nimm Claudes Texte als Entwurf und passe Sörens Grundnachrichten an die Person an. Ganz neue Formate stimmst du vorher mit Sören ab (Gruppen- oder 1:1-Call).
3. **Du bist verantwortlich:** Lies jeden Text, bevor du ihn postest oder abschickst.

## Updates

Der Skill wird laufend verbessert. **Er aktualisiert sich nicht von selbst** – jeder hat seine eigene Kopie in Claude.
Wenn es eine neue Version gibt, sagt Sören Bescheid. Dann:
1. In Claude unter **Skills** die alte Version von **sales4sells-content** entfernen
2. Die neue ZIP oben unter „Herunterladen“ laden und hochladen
3. Test: „Welche Version hat dein Sales4Sells-Skill?“ – Claude nennt die Versionsnummer
